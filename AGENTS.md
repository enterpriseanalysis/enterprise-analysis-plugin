# Enterprise Analysis plugin

Node 20+, ESM, MCP SDK. Run `npm test` and `npm run smoke` after behavior changes.
The backend is a separate read-only service. Keep exact model+reasoning keys, same-index comparisons, status flags, missing values and pricing coverage intact. Do not expose backend administrative or maintenance endpoints.
Do not commit credentials, internal backend source, API dumps or private deployment configuration. Local fixtures must be synthetic and marked as such.
Directory discovery and installed-tool invocation are separate evaluation stages. Never report a manual name search as spontaneous discovery.
